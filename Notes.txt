6. **History**: Maintain a log of all requests, approvals, allocations, and trips.

**Non-Functional Requirements:**
- User authentication and role-based access control (e.g., Worker, Department Head, HR, Driver).
- System scalability to handle multiple concurrent users.
- Mobile and web accessibility.
- Real-time notifications via email/SMS.

To implement a foreign key in your Sequelize models where a `Todo` item is linked to a `User`, you need to define the relationship between the models using Sequelize's `associations` methods (`belongsTo` and `hasMany`).

Here’s how you can do it:

### **1. User Model**
Define the `User` model with an `id` field that will act as the primary key.

```javascript
const { DataTypes } = require('sequelize');
const dbConnection = require('../../config/Db/db');

const UserModel = dbConnection.define('users', {
    id: {
        type: DataTypes.INTEGER,
        allowNull: false,
        autoIncrement: true,
        primaryKey: true
    },
    name: {
        type: DataTypes.STRING,
        allowNull: false
    },
    email: {
        type: DataTypes.STRING,
        allowNull: false,
        unique: true
    }
});

UserModel.sync();

module.exports = UserModel;
```

### **2. Todo Model**
Define the `Todo` model with a `userId` field that references the `id` field in the `User` model.

```javascript
const { DataTypes } = require('sequelize');
const dbConnection = require('../../config/Db/db');
const UserModel = require('./UserModel'); // Import UserModel

const TodoModel = dbConnection.define('todos', {
    id: {
        type: DataTypes.INTEGER,
        allowNull: false,
        autoIncrement: true,
        primaryKey: true
    },
    title: {
        type: DataTypes.STRING,
        allowNull: false
    },
    description: {
        type: DataTypes.STRING,
        allowNull: true
    },
    isCompleted: {
        type: DataTypes.BOOLEAN,
        allowNull: false,
        defaultValue: false
    },
    userId: {
        type: DataTypes.INTEGER,
        allowNull: false,
        references: {
            model: UserModel, // Reference the User model
            key: 'id' // Use the `id` field in the User model
        },
        onDelete: 'CASCADE', // Delete todos when the associated user is deleted
        onUpdate: 'CASCADE'  // Update todos when the associated user's id is updated
    }
});

// Define the association
UserModel.hasMany(TodoModel, { foreignKey: 'userId' });
TodoModel.belongsTo(UserModel, { foreignKey: 'userId' });

TodoModel.sync();

module.exports = TodoModel;
```

---

### **3. Syncing the Models**
Ensure the tables are created in the correct order by syncing the models sequentially.

```javascript
(async () => {
    await UserModel.sync();
    await TodoModel.sync();
})();
```

### **4. Example Usage**
Here’s how you can create a user and associate todos with that user:

```javascript
const UserModel = require('./UserModel');
const TodoModel = require('./TodoModel');

(async () => {
    // Create a new user
    const user = await UserModel.create({
        name: 'John Doe',
        email: 'johndoe@example.com'
    });

    // Create a new todo associated with the user
    const todo = await TodoModel.create({
        title: 'Buy groceries',
        description: 'Milk, eggs, and bread',
        userId: user.id // Link the todo to the user
    });

    console.log('User:', user.toJSON());
    console.log('Todo:', todo.toJSON());
})();
```

### **Key Points**
1. **Foreign Key Setup**: The `userId` field in the `Todo` model references the `id` field in the `User` model.
2. **Associations**: Use `UserModel.hasMany` and `TodoModel.belongsTo` to establish the relationship.
3. **Cascading**: Set `onDelete` and `onUpdate` options to maintain referential integrity.
