# Vehicle Allocation API Documentation

## Overview
This folder contains comprehensive documentation for the Vehicle Allocation API project. The documentation provides detailed information about the project's architecture, components, functionality, and implementation details.

## Files
- **project_documentation.md**: The main documentation file in Markdown format.

## Converting to Word Document
To convert the Markdown documentation to a Word document, you can use one of the following methods:

### Method 1: Using Pandoc (Command Line)
1. Install [Pandoc](https://pandoc.org/installing.html)
2. Open a command prompt or terminal
3. Navigate to the report folder
4. Run the following command:
   ```
   pandoc project_documentation.md -o project_documentation.docx
   ```

### Method 2: Using Online Converters
1. Open an online Markdown to Word converter like [Markdown to Word](https://word2md.com/) or [CloudConvert](https://cloudconvert.com/md-to-docx)
2. Upload the project_documentation.md file
3. Convert and download the Word document

### Method 3: Using Microsoft Word
1. Open Microsoft Word
2. Create a new document
3. Copy the content from project_documentation.md
4. Paste it into the Word document
5. Format as needed
