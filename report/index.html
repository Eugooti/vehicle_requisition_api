Converting to Word Document

To convert the documentation to a Word document:

  1. Open the HTML documentation in a web browser
  2. Use the browser's print function (Ctrl+P or Cmd+P)
  3. Select "Save as PDF" or "Microsoft Print to PDF" as the printer
  4. Save the PDF file
  5. Open Microsoft Word
  6. Open the PDF file in Word (File > Open)
  7. Save as a Word document (.docx)

Alternatively, you can open the HTML file directly in Microsoft Word and save it as a .docx file.
